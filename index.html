🧠 Нейросети × Сложные системы

Отклик сети, эмерджентность, фазовые переходы — нейросети позволяют обучаться на данных и предсказывать поведение систем, которые невозможно описать аналитически.

🌊 Динамический хаос

LSTM, Transformers для временных рядов. Прогноз аттрактора Лоренца, погоды, популяций.

🕸️ Графовые сети

GNN для моделирования соцструктур, транспортных потоков, биологических путей.

⚡ Агентное моделирование

Обучение с подкреплением для эмерджентного поведения в системах «много агентов».

📈 Регрессия и прогноз

Deep Learning для нелинейных систем, нейро-дифференциальные уравнения (Neural ODE).

🔮 Примеры моделирования

Каждый пример — нейросеть, обученная на данных реальной или синтетической сложной системы.

🐙 Как запустить проект через GitHub

Всё работает через страницу на GitHub Pages — ты просто копируешь репозиторий или форкаешь.

📦 1. Создай репозиторий

Название: neuro-systems-modeling. Загрузи туда index.html и папку с ассетами (если есть).

⚙️ 2. Включи GitHub Pages

Settings → Pages → Branch: main → Save. Через 1 минуту сайт уже живёт по ссылке:
https://твой-ник.github.io/neuro-systems-modeling/

💨 3. Автодеплой (опционально)

Создай файл .github/workflows/deploy.yml — и каждый пуш обновляет сайт автоматически.

📘 Гайд Pages

🚀 4. Доработки с анимацией

CSS анимации уже встроены, при скролле карточки выезжают, кнопки светятся. Можно добавить Three.js для 3D.
